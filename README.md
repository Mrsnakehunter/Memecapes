# MemeCapes

MemeCapes is a free 3D adventure game that runs in the browser, with an online world where players fight, gather,
trade and wear capes. This repository holds the game, the website at [memecapes.com](https://memecapes.com) and the
game server. Its trading companion, **snakepit** ([pit.memecapes.com](https://pit.memecapes.com)), lives in a separate
repository.

Everything here is plain HTML, JavaScript and Node.js: no framework, no build step for the website, and the server
has no npm dependencies.

## What is in this repository

| Path | What it is |
| --- | --- |
| `play.html` | The game: one self-contained file (WebGL renderer, world, combat, skills, bank, shop, trading window, chat). |
| `preview.html` | The next version of the game, before it ships. `tools/ship.sh` copies it to `play.html`. |
| `index.html` | The website: home, story, NPCs, items, towns, quests, token page, FAQ, support, security, terms. |
| `launch.html`, `lp/` | Watch (live trades on hatched coins) and Stream (go live from the browser or OBS). |
| `server/` | The game server: accounts, cloud saves, live players, chat, player trades, holder perks, streaming, launchpad trade indexer, security guard. See [server/README.md](server/README.md). |
| `models/` | 3D models (buildings, characters, trees, skins) converted from GLB by the tools below. |
| `tools/` | The build: `build.sh` rebuilds the game from its base by applying every `patch_*.py` in order; model converters (`glb2mdl.py`, `treepack.py`, `decimate.cpp`, `npc_clips.py`); site generators (`tools/site/`); test and screenshot helpers (`tools/dev/`); the Watchtower check (`watchtower.sh`). |
| `support/` | The support page's question-and-answer data, generated by `tools/site/support_qa.py`. |
| `memesnake/` | The page for MemeSnake, the project's AI agent, reading its live feed from the game server. |
| `PROGRESS.md` | The public log of what shipped and when, in plain words. |

The game world has computer-controlled adventurers that look like players, to keep quiet areas alive. They are never
counted as players anywhere (the online count and `/who` list real players only), and the website says so in its FAQ.

## Running it

The website and game are static files: serve the folder with any web server (for example `python3 -m http.server`)
and open `index.html` or `play.html`.

The server needs Node.js 22.13 or newer:

```sh
cd server
node server.js            # starts on PORT (default 8080); data in DATA_DIR
```

Settings are environment variables, listed in [server/README.md](server/README.md) and `render.yaml`.

## Tests

```sh
cd server
node test.js              # accounts, saves, live players, chat, trades
node test_holder.js       # holder perks against a fake blockchain
node test_guard.js        # the Sentinel guard: rate limits, blocks, modes
node test_pit.js          # the snakepit bridge
node test_plink.js        # linking a game account with snakepit
node test_memesnake.js    # the MemeSnake live feed
node test_crews.js        # MemeSnake's automated crews
node test_burns.js        # the public burn log against a fake blockchain
node test_withdraw.js     # withdrawals: wait, caps, cancel, payouts read from the chain
```

## Building the game

```sh
sh tools/build.sh         # rebuilds preview.html from the base + every tools/patch_*.py
sh tools/ship.sh          # copies preview.html to play.html and writes version.json
```

Each patch is an exact-text replacement with an assertion, so a patch fails loudly if the code it expects has moved.

## The token

The project's token, its official contract address and every official wallet are listed on the token page of
[memecapes.com](https://memecapes.com). Holder perks are in-game cosmetics only. There is no revenue share and nothing
here promises a return. MemeCapes is not affiliated with or endorsed by the creators of any meme shown in the game.

## Security

The server runs a guard (Sentinel: per-address limits, automatic blocks, a shield mode) and a scheduled Watchtower job
checks the live site against this repository. Report a problem through the contact on the website's support page.
